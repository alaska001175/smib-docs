# Репозиторий документации СМИБ (ISO/IEC 27001:2022)

Данный репозиторий предназначен для хранения и управления версиями документированной информации Системы Менеджмента Информационной Безопасности (СМИБ).

## Структура репозитория:
- `01-politika/` — Политика ИБ верхнего уровня
- `02-chastnye-politiki/` — Частные (тематические) политики
- `03-procedury/` — Процедуры и регламенты
- `04-instrukcii/` — Инструкции, шаблоны, чек-листы
- `05-zapisi/` — Шаблоны и реестры записей

## Порядок внесения изменений
Прямая запись в ветку `main` запрещена. Все изменения вносятся через создание тематических веток и проведение Pull Request / Merge Request с обязательным рецензированием.
